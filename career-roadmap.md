## 🎯 Top 3 Career Vectors

### Option 1: Technical Project Manager / Product Manager (Associate)

**Fit Score:** ⭐⭐⭐⭐⭐ (Best match to existing experience)

**Why It Works:**
- Already has PM experience from LP Roofing
- Communication skills are the #1 differentiator
- Hospitality trains deep customer empathy
- Doesn't require coding to start

**Bay Area Advantage:**
- Thousands of PM roles across startups and big tech
- Companies: Salesforce, Stripe, Figma, Notion, Airbnb all HQ'd here
- Strong PM community and networking events

**Salary Range (Bay Area):** $90K - $140K entry level

**Learning Path:**
- [ ] Google Project Management Certificate (Coursera) – ~3-6 months
- [ ] Learn Agile/Scrum fundamentals
- [ ] Get familiar with tools: Jira, Linear, Notion, Figma
- [ ] Optional: Learn SQL basics for data-informed decisions

**Target Roles:**
- Associate Product Manager (APM)
- Technical Project Manager
- Program Coordinator → Program Manager
- Operations Manager (tech company)

**Bay Area Companies with APM Programs:**
- Google APM Program
- Meta Rotational PM
- Salesforce Futureforce
- LinkedIn APM
- Kleiner Perkins Fellows (VC-backed startups)

### Option 2: Developer Relations / Developer Advocacy

**Fit Score:** ⭐⭐⭐⭐ (Great if wants to learn coding)

**Why It Works:**
- Journalism + communication background is exactly what DevRel needs
- Role is about community, content, and explaining tech concepts
- People skills from hospitality translate directly
- Can learn to code at intermediate level (not expert required)

**Bay Area Advantage:**
- DevRel was basically invented here
- Major DevRel employers: Twilio, Stripe, GitHub, Vercel, MongoDB
- Active DevRel community and meetups

**Salary Range (Bay Area):** $100K - $150K entry level

**Learning Path:**
- [ ] Learn JavaScript or Python fundamentals (3-6 months)
- [ ] Build 2-3 small projects and document them
- [ ] Start a technical blog or YouTube channel
- [ ] Contribute to open source (even documentation counts)
- [ ] Attend local meetups and start speaking

**Target Roles:**
- Community Manager (tech company)
- Developer Advocate (Junior)
- Technical Writer
- Developer Experience Engineer

**Bay Area Companies Hiring DevRel:**
- Twilio, Stripe, Vercel, Supabase
- Auth0/Okta, MongoDB, Cloudflare
- Startups via AngelList

### Option 3: Sales Engineering / Technical Account Manager

**Fit Score:** ⭐⭐⭐⭐ (Highest earning potential)

**Why It Works:**
- Hospitality = relationship building + handling objections
- Bilingual Spanish = access to LATAM markets (massive advantage)
- Can learn technical concepts on the job
- Personality-driven role

**Bay Area Advantage:**
- Enterprise SaaS capital of the world
- Bilingual sales talent is in HIGH demand
- Clear career ladder to $200K+ total comp

**Salary Range (Bay Area):** $90K - $180K+ (base + commission)

**Learning Path:**
- [ ] Salesforce Administrator certification
- [ ] AWS Cloud Practitioner or Azure Fundamentals
- [ ] Learn one product category deeply (CRM, Security, DevTools, etc.)
- [ ] Practice demo/presentation skills

**Target Roles:**
- Sales Development Rep (SDR) → fastest entry
- Business Development Rep (BDR)
- Technical Account Manager
- Solutions Consultant (Junior)

**Bay Area Companies Hiring:**
- Salesforce, Databricks, Snowflake
- Palo Alto Networks, CrowdStrike
- Zoom, Slack, Atlassian
- Any funded Series B+ startup
