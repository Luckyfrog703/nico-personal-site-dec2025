Housing - Bay Area

Bay Area Rental Sifter

Sifts real Bay Area listings and automatically flags traps: Section 8 lotteries, senior-only buildings, income-restricted waitlists, and suspiciously cheap listings.

Problem

Affordable-looking listings routinely are not what they seem, and renters burn hours sorting through them.

Findings

Traps announce themselves in listing text (Section 8 welcome, 55+, BMR, lottery, income restricted). There is no clean public listings API, so the honest strategy is public sources that permit access, with cards linking back to the original post. A price far below comparables is a suspicion signal.

Decisions

  • Real listings only, no sample data.
  • RESTRICTED flags are hidden by default, with a toggle.
  • Suspiciously cheap - verify first warnings are benchmarked against the current batch.
  • A paste-a-listing checker highlights the exact red-flag phrases.
  • A shortlist pipeline: interested, contacted, touring, applied.

Outcome

A live app pulling about 190 real listings per refresh from public sources, refreshed automatically every morning. The first run caught a real SECTION 8 WELCOME listing and a below-market listing flagged from its body text. Disclosed imperfection: one RV-space post was labeled Studio because the source lists 0 bedrooms; it was still correctly flagged verify-first.

Metrics

Percentage flagged; checker usage; shortlist conversion to applied.

Roadmap

Version 2: alerts for new unflagged matches. Version 3: per-area typical-rent benchmarks.

Interactive app — happy to demo live on request.
